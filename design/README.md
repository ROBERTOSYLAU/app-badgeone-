# Design Assets

Pasta para arquivos de design, inspiracoes e identidade visual do BadgeOne.

## Estrutura

- `logos/` — logotipos e variacoes (PNG, SVG, JPG)
- `inspiracao/` — referencias visuais e inspiracoes de UI/UX
- `mockups/` — telas e prototipos

## Como usar

Faca upload das imagens aqui pelo GitHub e informe o caminho para que Claude Code possa analisá-las.
